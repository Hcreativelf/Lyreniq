# YIN 鲁棒性与性能记录

2026-11-25（Asia/Shanghai），T07；起点 58830d6536561526af734ee55ecb201a6984225b。纯 Rust/标准库，不包含设备、FFT 频谱或 UI 接入。

## 算法和对照

YinDetector::detect 是 T07 路径；detect_reference 保留 T06 完整 lag 差分、累计归一化和三点插值。26 个冻结 T06 CSV 频率通过 2e-9 Hz 容差回归，不改写旧证据。实际采样率、去 DC/RMS、固定比较段 W、频率范围及零或一个估计的契约不变。

- 逐 lag 归一化，首谷出现后提前结束大部分搜索；四路独立累加减少长依赖链，使用安全 as_chunks，无 unsafe 或新依赖。无谷仍扫描全范围，最坏复杂度仍 O(W×max_lag)。
- 谷深 >0.001 时检查二/三倍周期附近 ±2 lag，只有局部谷至少改善十倍才选择较长周期，优先二倍再三倍；受配置范围限制。它修复本轮强泛音夹具，不保证所有非谐和乐器或混音。
- 原始差分使用五点四次拟合。stride=max(1,floor(lag/32))，受左右可用数据限制；最多五次 Newton 步，要求正曲率、有限值、有界位移，否则退回三点插值。stride=1 限制 ±1，其余限制 ±2 个局部单位。更宽的低频拟合跨度降低相邻 lag 噪声影响，CMNDF 仍决定接受状态和置信度。已用已知四次函数顶点及不同 stride 单测；这不是原论文的插值步骤。
- 当差分 ≤去 DC 均方能量×W×f64::EPSILON 时，采用已观察到的整数重复周期，避免近零残差被插值移到边界外。没有将输出频率夹到配置端点；其他情况仍严格检查范围。
- 默认保持 300 ms、20–5000 Hz、CMNDF 0.1、−60 dBFS。NoPitch/LowConfidence 不留旧音高，confidence 是周期性而非正确概率或误差界。

## 平滑与无效帧

PitchSmoother::process 接受检测 Result，返回 SmoothedPitch：raw() 完整保留原始 PitchDetection，display_frequency_hz() 单独给出展示值。固定三帧中值，无历史队列分配；不足三帧立即显示新值。原始频率跳变 >50 cents、NoPitch/LowConfidence 或错误立即清空历史；stop/session/采样率变化由未来 worker 调用 reset()。

20 ms 步长的历史跨度为 40 ms，单调变化通常落后一帧。测试验证跃变/无效状态第一帧更新或清空、错误后重启、颤音保持频带；不代表采集到界面的端到端延迟，300 ms 分析窗口的响应另算。

## 夹具与误差

[逐帧 CSV](evidence/T07/frame-errors.csv)、[分组摘要](evidence/T07/summary.json)：32 场景×44.1/48 kHz×5 个重叠窗口×2 引擎，共 640 行。窗口 300 ms、步长 20 ms；五个窗口不是五次独立随机试验。

- 13 个纯音：20/27.5/55/110/123.45/220/C4/432.123/440/442/880/1760/5000 Hz，幅度 0.5，不同连续信号起点。
- 泛音基频 110 Hz：1/2/3 次幅度 0.02/0.46/0.4；强二次 0.05/0.8；强三次 0.05/0.8；缺基频仅 2/3 次 0.45/0.45。
- 55/110/440 Hz 幅度 0.1，各叠加 20/10/0 dB SNR。64 位 LCG 种子 0x4c5952454e495107，与频率位模式异或；按完整夹具去 DC 能量缩放，实测 SNR 误差 <0.001 dB，无削波或隐式增益。单个窗口的 SNR 可略有变化。
- 110 Hz 加 0.6 DC；指数衰减到起始幅度的 1%；全零、常量 DC、低电平和纯噪声。

| T07 类别 | 有效/总帧 | 最大绝对偏差 | 不变的验收门槛 |
|---|---:|---:|---|
| 纯音 | 130/130 | 0.162534 cents | ≤1 cent |
| 四种泛音 | 40/40 | <0.01 cent | ≤1 cent |
| 20 dB SNR | 30/30 | 0.299696 cent | ≤5 cents |
| 10 dB SNR | 30/30 | 5.085480 cents | 接受帧 ≤10 cents，允许无音高 |
| 0 dB SNR | 0/30 | 无有效估计 | 此夹具返回无音高 |
| DC/衰减 | 各 10/10 | 衰减 <0.93 cent | DC ≤1、衰减 ≤5 cents |
| 静音/DC 常量/低电平/纯噪声 | 0/40 | 无有效估计 | 不产生音高 |

已知目标的 280 帧中，T06 接受 244（87.1429%），T07 接受 250（89.2857%）；T07 拒绝的 30 帧均为 0 dB SNR。无有效估计的误差保持缺失。泛音子集 40 帧，八度错误 T06 10/40=25%、T07 0/40；计入三倍频的粗大错误分别为 20/40、0/40。八度错误定义为偏差距非零整数×1200 cents ≤50 cents；粗大错误为 |error|>600 cents。

20 Hz 现在两采样率、五起点均有效（10/10）。5000 Hz 相位零误差由约 −1.319302/−0.959542 降至 −0.162533/−0.093746 cents。只证明这些离散点/夹具，不保证连续 20–5000 Hz 或真实乐器精度。

## 单机性能与 CPU

[机器/CPU](evidence/T07/machine.json)、[全部耗时](evidence/T07/timings.csv)：i5-14600KF，20 逻辑处理器，Windows NT 10.0.26300.0，Rust 1.100.0，Release 默认 Windows x64 目标特性。用户继续使用桌面；正式基准时本代理未并发构建，非隔离环境，未固定频率或核亲和性。

每场景 3 次预热后测 64 次，Instant 墙钟、black_box 消费结果；p95 为 nearest-rank。包含 PCM 校验、RMS 和检测，预热后复用缓冲；不含采集、FFT、worker、IPC。五类场景为 20/27.5/440 Hz、强二次泛音和纯噪声，各两采样率。

| 48 kHz / 300 ms | T06 p50/p95 ms | T07 p50/p95 ms |
|---|---:|---:|
| 20 Hz | 11.0329 / 11.2477 | 3.2544 / 3.4791 |
| 27.5 Hz | 11.0275 / 11.2568 | 2.3894 / 2.5005 |
| 440 Hz | 11.0466 / 11.3099 | 0.1646 / 0.2015 |
| 强二次泛音 | 11.0639 / 11.3414 | 0.8888 / 0.9549 |
| 纯噪声 | 10.9864 / 11.4105 | 3.3977 / 3.5552 |

所有已测 T07 场景最坏 p95=3.5552 ms、单次=3.6437 ms；检测核心满足 30 Hz 的 33.3 ms 预算。不能据此声称整个未实现管线已达到目标。

隐藏独立进程分别运行仅基准模式，每引擎 640 次计时调用+30 次预热：T06 CPU 6.78125 s / 墙钟 6.85769 s；T07 CPU 1.265625 s / 墙钟 1.27486 s。批处理持续占约一个逻辑核（整机约 4.9–5.0%），这不是未来定时应用的 CPU。进程 CPU 包含生成、预热和输出；帧分位数不含这些，统计口径不同。

T10 预算建议：常规模式显式约 100 ms/50–5000 Hz、20–30 Hz；低音用 300 ms/20–5000 Hz、10–20 Hz，接受更长观察延迟。如果耗时超步长则降低检测频率，只保留最新窗口，禁止无界追赶。这是后续配置/调度建议，尚无 worker、动态窗口或设备性能验收。

## 复现及限制

```powershell
cargo test -p tuner-core --locked
cargo test -p tuner-core --release --locked
powershell.exe -NoProfile -File scripts/bench-yin.ps1
```

基准脚本已从 D:\ 用绝对路径经 Windows PowerShell 5.1 运行成功。它依次启动 CreateNoWindow 进程，输出 .local/dsp-bench/<UTC时间>/full.csv、cpu-T06.csv、cpu-T07.csv、machine.json 和 latest.json。full.csv 的 FRAME 行为误差数据，BENCH 行为交错计时；提交的 timings.csv 来自两个独立 CPU 基准进程。也可直接 cargo run -p tuner-core --example yin_report --release --locked。

正式原始目录 .local/dsp-bench/2026-11-25T09-40-27-263Z；较早试跑及曾并发构建的报告仅在 .local/logs，未用于正式性能表。首次固定矩阵暴露约 43.55 cents 的 10 dB 低音偏差，扩大拟合跨度后通过原 10 cents 断言，没有降低门槛。常量 chunks_exact 的 Clippy 提示以 as_chunks 解决，未禁用检查。

当前核心 4 单元+33 集成+2 文档通过。尚无更多噪声种子、真实设备时钟/音色、非谐和乐器、混音/和弦、完整 worker/FFT/IPC 预算或长时设备稳定性证据。本轮合成 PCM 不播放声音；真实采集仍留给 T09 及后续任务。
