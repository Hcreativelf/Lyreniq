## 1. 产品定位与核心目标

**Lyreniq** 是一款完全本地运行、现代专业的通用乐器调音与音准分析桌面软件。第一里程碑交付 **Windows 10/11 x64 桌面 MVP**，架构面向未来跨平台（macOS / Linux / Web WASM / Mobile）及复音扩展保持清晰边界。

### 1.1 Windows MVP 功能范围（F01–F09）

| ID | 功能 | Windows MVP 验收目标 |
|---|---|---|
| F01 | 实时调音 | 自动/目标音名、八度、Hz、cents、偏高/偏低/准确、输入电平、置信度、近期音高轨迹 |
| F02 | 输入源管理 | 枚举并选择麦克风、可选 **Windows WASAPI Loopback（系统声音内录）**、内置虚拟测试流；开始/停止、热插拔与权限错误恢复 |
| F03 | 实时频谱 | Hann 窗幅频谱、对数频率坐标、相对 dBFS、基频与可信谐波标注、Canvas 2D 高帧率绘制 |
| F04 | 本地文件解码 | WAV / FLAC / MP3 流式解码，声道选择与反相提示，进度、取消与损坏/截断文件错误处理 |
| F05 | 文件音高分析 | 恒定内存滑窗单音时间轴、无音高断线、缩放/平移/悬停读数、有效帧统计与 CSV（含配置元数据）导出 |
| F06 | 乐器预设 | 通用半音、吉他、贝斯、尤克里里、小提琴、中提琴、大提琴、通用钢琴模式、自定义目标音列表；自动选弦与手动锁弦 |
| F07 | 参考音发生器 | 音名网格或自定义 Hz、跟随全局 A4、安全默认低音量、淡入淡出防爆音、与监听并存时明确串音提醒与一键暂停监听 |
| F08 | 本地设置 | A4 校准（400–480 Hz）、容差、升降号、检测范围/响应模式、输入源偏好、深浅主题；版本化本地持久化与坏配置安全回退 |
| F09 | 打包与交付 | Windows 安装包（NSIS/MSI 及明确 WebView2 策略）、SHA-256、完全离线验收、可复现源码与文档 |

### 1.2 第一版明确不做

- 复音/和弦分离与混合歌曲自动转谱（数据结构保留 `Vec<PitchEstimate>` 扩展口，V1 输出 0 或 1 个基频）。
- 钢琴拉伸调律（stretch tuning）、复杂微分音律、移调乐器自动移调显示、DAW/VST 插件、录音编辑。
- 账号、云同步、遥测、在线更新、运行时 CDN 或远程字体。
- macOS / Linux / Web / Android / iOS 实际发布（架构预留边界，不在 Windows MVP 阶段实现未验证平台代码）。

## 2. 四层软件架构（v2.0）

相比 v1.0 仅划分 DSP/IO/Decode 与桌面胶水，v2.0 引入纯 Rust、平台无关的 **`tuner-engine` 应用编排层**，让 `src-tauri` 保持极薄壳层，使全部核心算法、实时调度、离线分析、预设和配置模型可 100% 跨平台复用：

│ Layer 4: UI & Thin Desktop Shell (apps/desktop)                      │
│  • apps/desktop/src/       : React 19 UI + Canvas 2D (仪表/轨迹/频谱 │
│                              /时间轴) + 统一 AudioBackend 适配层      │
│  • apps/desktop/src-tauri/ : 极薄桥接（Commands / Tauri Channel /    │
│                              受限原生弹窗 / 应用数据目录 / 退出清理） │
├──────────────────────────────────────────────────────────────────────┤
│ Layer 3: Application Engine (crates/tuner-engine, 纯 Rust, 跨平台)    │
│  • LiveSession       : 消费有界环形缓冲、步长调度、过载丢旧帧、会话ID │

│  • InstrumentProfile : 数据驱动乐器预设、推荐频率范围、自定义目标     │

│                           + Windows WASAPI Loopback（可选系统内录）   │
│                           + CPAL 参考音输出（相位连续、淡入淡出）     │
│                           + 虚拟时钟流源（用于无麦克风全链路验证）    │
│  • crates/audio-decode/ : Symphonia 流式解码（WAV / FLAC / MP3）      │

│  • tuning   : 十二平均律、A4 校准、MidiNote、目标匹配（保留并增强）   │

│  • synth    : 相位连续波形发生器（服务测试夹具与参考音输出）          │

### 2.1 实时线程与音频回调红线

- **音频回调（CPAL 输入 / Loopback / 输出）**：仅允许预分配无锁缓冲读写、样本格式转换、相位累加和轻量原子计数；严禁 FFT、YIN、动态堆分配、阻塞锁、磁盘 I/O 或 IPC。
- **有界背压与会话隔离**：环形缓冲满时记录 `dropped_frames` 并推进到最新样本，严禁无界积压；所有实时帧与离线任务均携带单调递增 `session_id` / `job_id`，切换源或停止后立即隔离过期帧并释放流。
- **单一真相来源**：音律换算、容差判定、平滑展示值与对数频谱分桶均在 Rust 端完成，前端只做展示和交互，不在 TS 侧硬编码 A4 或容差逻辑。
- **高频通道优化**：实时音高快照与压缩后的对数频谱（例如 256–512 个视觉桶）通过 Tauri 2 `Channel` 节流推送；前端使用 Canvas 2D + `requestAnimationFrame` 渲染高频指针阻尼、音高轨迹与频谱，避免 React 高频 DOM 重排。

## 3. DSP 2.0 算法设计要点

### 3.1 统一 FFT 频谱与 Fast YIN 协同

1. **FFT 频谱分析器（`SpectrumAnalyzer`）**：
   - 使用 `rustfft` 预构建 planner 并复用全部缓冲（无每帧分配），支持 2048 / 4096 / 8192 可配置长度。
   - 应用 Hann 窗，进行明确的相干增益归一化（幅度谱 $2|X_k| / \sum w_n$，DC 与 Nyquist 不乘 2），相对满幅 dBFS（不冒充 dB SPL），彻底杜绝 `NaN`/`Infinity`。
   - 提供**对数频率轴分桶视图**（例如 20 Hz–Nyquist 按对数映射到 $M$ 个显示柱，取每桶峰值 dBFS），兼顾低频视觉分辨率与低 IPC 带宽。
   - 提供基频谐波能量查询，辅助频谱标注与基频倍频验证。

2. **FFT 加速 Fast YIN + 双尺度窗口（`PitchDetector`）**：
   - 使用 Wiener–Khinchin 恒等式计算 YIN 差分函数：
     $$d(\tau) = \sum_{j=0}^{W-1} x_j^2 + \sum_{j=0}^{W-1} x_{j+\tau}^2 - 2 \sum_{j=0}^{W-1} x_j x_{j+\tau}$$
     前两项通过前缀平方和 $O(1)$ 计算，互相关项通过一次长度为 $2^k \ge 2W$ 的 FFT 在 $O(N \log N)$ 完成。无论纯音还是纯噪声（无早停最坏情况），每帧计算耗时恒定且显著低于时域暴力循环。
   - **双尺度检测策略**：
     - **常规/快速路径**（如 ~85 ms 窗口，适合 55–5000 Hz）：高音与吉他/小提琴换弦响应极快（<100 ms）。
     - **低音路径**（4x 低通降采样或长窗口，适合 20–120 Hz）：可靠覆盖钢琴 A0（27.5 Hz）与 5 弦贝斯 B0（30.9 Hz），同时大幅削减计算量并抑制高频噪声。
     - 兼容显式固定窗口配置（60–300 ms），保证既有 640 帧回归夹具与精确控制场景无缝工作。
   - **稳健八度纠错**：结合 YIN 局部谷深改善比与频谱谐波显著性验证 2x/3x/4x 周期候选，避免硬编码严苛阈值在真实非谐性乐器上发生八度跳变；使用高精度抛物线/局部精细插值，保证稳定合成音目标 $\le \pm 1\text{ cent}$。

3. **对数频率域 `PitchTracker`（替代简单 Hz 中值）**：
   - 严格保持 `raw` 原始测量与 `display` 展示频率分离。
   - 所有滤波在**音分 / $\log_2 f$ 域**执行，确保不同八度响应一致。
   - 具备：短窗口中值去野点 + 音分域自适应 EMA（大变化快追、小抖动稳锁）+ 可配置短丢帧保持（hangover，防止瞬时低置信度造成界面闪烁）+ 音符大跳变（>50 cents）与生命周期切换立即重置。

## 4. UI 与交互原则

- 延续已确立的石墨灰/暖白/薄荷绿语义 token、深色默认/浅色可选与 WCAG $\ge 4.5:1$ 对比度标准。

- 顶栏与页面状态统一：直接提供输入源选择（麦克风 / 系统声音 / 内置测试音）、开始/停止监听与全局 A4 状态。
